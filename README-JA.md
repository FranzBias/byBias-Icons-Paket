**byBias-Icons-Packet** は byBias のアイコンツール一式を単一の GTK3
アプリにまとめたもので、*あなた自身の*アイコンコレクションを管理するために
作られました：抽出、整理、一貫した命名、そしてテーマ化まで。このアプリで
作った自由なアイコンテーマ（GPL-3）も準備中です。メインウィンドウは
ダッシュボードで、各アクションが
見えるカードになっており、クリックすると同じウィンドウ内にそのパネル
が開きます — メニューを掘り下げる必要も、コマンドを覚える必要もあり
ません。

## 機能

**メインフロー**は、アイコンテーマを最初から最後まで構築・維持する日
常的な作業をカバーします：

- **アイコン抽出** — `.ico`・`.exe`・`.dll`・`.icl` ファイル（名前変
  更済みで別物に見えるものでも）からアイコンを抽出し、透過を保持した
  きれいな PNG を再構築します。ダウンロードしたアイコンパックが実は
  変装した Windows 実行ファイルだった、という場合に便利です。
- **テーマの作成 / 更新** — ソースフォルダを本物のアイコンテーマにコ
  ピーします：ファイル名・フォルダ名を整理し（スペース/アンダースコ
  ア → ハイフン、アクセント記号を除去）、正しい `index.theme` を生成
  してキャッシュを再構築し、ワンクリックでシステム全体にテーマを適用
  できます。
- **アイコンの適用** — *あなた自身の*カテゴリー（システムの汎用カテ
  ゴリーではなく）で整理されたセレクターにより、コレクションを視覚的
  に閲覧し、任意のアイコンをフォルダに適用できます。
- **シンボリックアイコン** — フルカラーの PNG を、パネルやメニューで
  使われる、ライト・ダークテーマに応じて自動的に色が変わる単色 16×16
  の「シンボリック」SVG アイコンに変換します。
- **巨人狩り** — あなたのアイコンとシステムアイコンとの名前の衝突を検
  索します。名前の衝突は、アイコンが突然巨大に表示されたり、壊れた画
  像の三角形として表示されたりする典型的な原因です。
- **すべてにプレフィックス** — 安全で手間のかからない選択肢：テーマ内
  のすべてのアイコンに `bybias-` プレフィックスを付け、誤ってシステム
  アイコンを置き換えることが決してないようにします。
- **システムアイコンの置き換え** — システムスロット（ゴミ箱の満杯/空、
  汎用フォルダ、ホームフォルダなど）を選び、自分の画像を用意すると、
  正確な標準名でインストールされ、デスクトップ上でそのアイコンが表示
  されるあらゆる場所に取って代わります。

メインフローに加え、ダッシュボードにはより専門的なツールが 4 つのセ
クションにまとめられており、それぞれが特定の悩みを解決します：

**メンテナンス** — 大きなコレクションを長期にわたって整理された状態
に保つ。
- *重複を検出* は、ファイル名ではなく画像の実際の内容（ピクセルのハ
  ッシュ値）でアイコンを比較し、異なる名前で 2 回保存された同じアイ
  コンを見つけ出します。
- *コンタクトシート* は、コレクション全体を 1 枚のラベル付き PNG モ
  ザイクとして描画します — フォルダを 1 つずつクリックする代わりに、
  実際に何を持っているかを *見る* ための本当に便利な方法です。
- *類似アイコンを検索* は、1 つの参照アイコンを基準に、支配的な色が
  どれだけ近いかでコレクションの残りを並べ替えます。視覚的にまとまり
  のあるサブセットを作るのに役立ちます。

**制作** — 実際の使用のためにアイコンを仕上げる。
- *サイズを正規化* は、大きすぎる元の PNG から、標準サイズ（16 から
  256 px）の完全なセットを生成します。システムに任せてその場で粗く拡
  大縮小させるのではなく、適切にリサイズされます。
- *色変更・反転* は、モノクロアイコンに選んだ色合いを適用したり、明
  暗を反転させたりして、シンボリックセットを逆のテーマに合わせられる
  ようにします。
- *トリミングして中央揃え* は、不均一な透明の余白を取り除き、統一さ
  れたパディングでアイコンを再センタリングします — 特に理由もなくど
  こか「歪んで」見える混在セットの解決策です。

**配布** — 作ったものを共有する。
- *パッケージを書き出し* は、テーマを自動生成された `LICENSE` と
  `README` とともに zip にまとめ、公開準備を整えます。
- *ショーケースを生成* は、選りすぐったアイコンから宣伝用画像を作成
  します。ダウンロードページに載せたくなるようなものです。

**安全性と利便性** — セーフティネット。
- *バックアップ・復元* は、リスクのある変更の前にテーマのタイムスタ
  ンプ付きスナップショットを作成し、何か問題が起きてもワンクリックで
  元に戻せるようにします。
- *ヘルスチェック* は、テーマ全体を診断チェックリスト（継承関係、ア
  クセント記号付きの名前、名前の衝突、キャッシュの有効性）にかけ、問
  題が巨大アイコンや壊れた画像の三角形になる *前に* 検出します。

ウィンドウ左上のメニュー（☰）から、**このアプリについて**（GitHub
リンクを含む）、この README の 10 言語すべてに対応した**言語切り替
え**、そしてアプリ自体の**ライト/ダークテーマ**の切り替えに素早くア
クセスできます。

## 必要環境

```bash
sudo apt install python3-gi gir1.2-gtk-3.0 gir1.2-xapp-1.0 python3-pil icoutils
```

初回起動時に依存関係が不足している場合、byBias-Icons-Packet はそれを
検出し、必要なものを正確に一覧表示し、明示的な同意を求めたうえで、シ
ステム自体のグラフィカル認証（pkexec）または sudo 経由でインストール
します — つまり、そのまま起動して自動的にセットアップさせることもで
きます。パスワードは常にシステムが管理し、アプリ自身が扱うことは決し
てありません。

## 実行

```bash
python3 icons-packet
```

**構成** — `icons_packet_core.py` はすべてのロジックを保持します
（GTK 非依存で、単独でテスト可能）。`icons_packet_gui.py` は GTK3 の
ダッシュボードです。`icons-packet` はランチャーで、上記の依存
関係チェックも担当します。

**命名規則** — ファイル名・フォルダ名はハイフン（`-`）のみを使用し、
スペースやアンダースコアは使いません。アプリはテーマを扱うたびに両方
を自動的に変換します。
